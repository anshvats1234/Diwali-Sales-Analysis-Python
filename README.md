**Diwali Sales Analysis Using Python**

**Project Overview**

This project analyzes Diwali sales data to identify customer purchasing behavior, sales trends, and product performance.

**Tools Used**

- Python
-  Pandas
- NumPy
- Matplotlib
- Seaborn

**Key Insights**

- Married women were the highest buyers.
- Most purchases came from the 26-35 age group.
- Uttar Pradesh, Maharashtra, and Karnataka generated the highest sales.
- Food, Clothing, and Electronics were top-selling categories.
